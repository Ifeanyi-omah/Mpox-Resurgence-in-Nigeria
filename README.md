# Mpox resurgence in Nigeria

Data, BEAST configurations and figure code for the analysis of the 2024–2025
resurgence of monkeypox virus (MPXV) clade IIb in Nigeria.

## Abstract

Mpox virus (MPXV) has shifted from mainly zoonotic transmission to sustained human
epidemics. Nigeria is the origin of the Clade IIb/sh2017 epidemic that seeded the 2022
multi-country outbreak. Despite the subsequent global decline, Clade IIb/sh2017 cases
resurged across West Africa from 2025, involving lineages previously detected in Nigeria.
Limited genomic surveillance left unresolved whether this resurgence represented a new
zoonotic spillover or continued human transmission in Nigeria. Here we integrated national
surveillance data with 146 newly generated MPXV genomes and performed phylodynamic and
phylogeographic analyses. We show that the 2024–2025 resurgence was driven predominantly by
established human-transmitted lineages. 92% of genomes belonged to Clade IIb/sh2017, with
A.2.2 replacing A.2.3 and spreading across all six geopolitical zones. Transmission
intensified from July 2024 (Re = 1.13, 95% HPD 1.04–1.22), prior to the outbreaks in Sierra
Leone, and Togo, and repeated introductions into Ghana and Côte d'Ivoire before recognition.
Twelve genomes represented independent zoonotic spillovers from divergent
reservoir-associated lineages in southern Nigeria and the Nigeria–Cameroon border region.
These findings identify Nigeria as a major source population for ongoing Clade IIb/sh2017
diversification and international spread, and highlight the need for continuous surveillance
for effective interventions.

## Repository layout

| Path | Contents |
|---|---|
| `Data/` | Alignments, trees, national surveillance tables and the per-figure input sets (`Figure1_data` … `Figure6+data`) |
| `BEAST/` | BEAST XML configurations for every time-scaled analysis, gzipped |
| `Scripts/` | Python and R code that builds each figure |
| `Figure/` | Rendered figures — PDF, SVG and PNG — one directory per figure |

## Large files

Ten input files are 47 MB or larger, and six of them exceed GitHub's 100 MB hard limit, so
they are tracked here in gzipped form (about 5x smaller) and the uncompressed copies are
listed in `.gitignore`. Rendered figures, including the 46 MB supplementary SVG, are kept
uncompressed so they open directly. Restore them with:

```bash
gunzip -k BEAST/*.xml.gz
gunzip -k Data/*.gz
```

BEAST posterior samples (`.trees`, `.log`) are not in the repository — a single posterior
tree file is larger than everything here combined. They can be regenerated by running the
XMLs, or requested from the authors.

## Analyses

| BEAST XML | Analysis |
|---|---|
| `NCDC+SKD+284.xml` | SkyGrid coalescent, 284 Nigerian clade IIb/sh2017 genomes |
| `NCDC+SKD+284+EBDS.xml` | Episodic birth–death sampling, epochs fixed to the three epidemic waves |
| `NCDC+EXP+DTA+284.xml` | Asymmetric discrete phylogeography, Nigerian states |
| `NCDC+Region+DTA+284.xml` | Asymmetric discrete phylogeography, six geopolitical zones |
| `NCDC+CONT+PHY+284.xml` | Continuous phylogeography, relaxed random walk |
| `REGIONAL+MPOX+INTER+2026-09.xml` | 569-genome international clade IIb/sh2017 analysis |

All Bayesian analyses use the partitioned APOBEC3 substitution model: a non-APOBEC3
partition under GTR+Γ and an APOBEC3 partition recoded to two states (C and T, with G and A
aliased) evolving under an asymmetric CTMC that permits C→T only, each partition carrying
its own clock. See the manuscript Methods for priors, chain lengths and convergence
diagnostics.

## Software

| Tool | Use |
|---|---|
| `squirrel` | Alignment to NC_063383.1, masking, quality control, APOBEC3 reconstruction |
| IQ-TREE 2 | Maximum-likelihood phylogenies and ancestral state reconstruction |
| Nextclade v3 (`nextstrain/mpox/all-clades`) | Clade and outbreak-lineage assignment |
| BEAST X with BEAGLE | Time-scaled phylogenetics, phylogeography, EBDS |
| Delphy v1.4.1 | Time-scaled phylogeny behind the export analysis |
| Tracer, LogCombiner, TreeAnnotator | Convergence assessment and posterior summary |
| `baltic` | Tree layout in the figure scripts |
| `seraphim` | Dispersal statistics from the continuous phylogeography |

## Reproducing the figures

Each script reads from the matching directory under `Data/` and writes PDF, SVG and PNG into
`Figure/`. Run them from the repository root, for example:

```bash
python Scripts/fig6.py
```

Figures are exported with live text (`pdf.fonttype 42`, `svg.fonttype none`), so labels stay
editable in Illustrator or Inkscape.
